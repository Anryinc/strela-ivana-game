# Стрела Ивана — Царевна-лягушка

2D side-view skill-game по мотивам русской народной сказки.

## Как играть

1. Открой `index.html` в браузере (или задеплой на GitHub Pages).
2. Выбери брата в меню.
3. **Прицеливание**: WASD / стрелки — угол, зажми ЛКМ или Пробел — сила, отпусти — выстрел.
4. **Полёт стрелы**:
   - WASD / стрелки — маневрирование
   - **Q** — щит (временная неуязвимость)
   - **E** — рывок вперёд
   - **Q + E** одновременно — замедление времени (меняет палитру)

## Уровни

| Уровень | Брат              | Цель                  | Сложность | Сказочные персонажи |
|---------|-------------------|-----------------------|-----------|---------------------|
| 1       | Старший брат      | Дом боярской дочки    | Лёгкий    | 1                   |
| 2       | Средний брат      | Дом купеческой дочки  | Средний   | 3                   |
| 3       | Иван-царевич      | Лягушка на пне        | Сложный   | 6                   |

## Концовки

- **Успех** — свадьба с правильной невестой
- **Провал** — свадьба с тем, во что попала стрела (с огромными удивлёнными глазами)
- **Секрет** — промах мимо цели → уезжает биться со Змеем Горынычем

## Сказочные персонажи и способности (1 раз за уровень)

- Баба-Яга — ослепление
- Кощей — заморозка управления
- Леший — выращивает деревья
- Избушка на курьих ножках — топот (тряска + толчок вниз)
- Водяной — замедление
- Кикимора — запутывание (разворот вертикальной скорости)
- Соловей-Разбойник — свист (тряска + хаотичный толчок)
- Морозко — заморозка

## Технологии

- Phaser 3 (CDN)
- Чистый JavaScript (ES modules)
- Procedural pixel-art текстуры
- Полностью статическая — идеально для GitHub Pages

## Деплой на GitHub Pages

1. Settings → Pages → Source: Deploy from branch `main` / root
2. Через минуту игра будет доступна по адресу:
   https://anryinc.github.io/strela-ivana-game/

## Управление

| Клавиша     | Действие              |
|-------------|-----------------------|
| W / ↑       | Вверх                 |
| S / ↓       | Вниз                  |
| A / ←       | Замедлиться           |
| D / →       | Ускориться            |
| Q           | Щит                   |
| E           | Рывок                 |
| Q + E       | Замедление времени    |
| Пробел/ЛКМ  | Натянуть лук (прицел) |
